# Particle Fluids

Theme: Fluids, Smoke & Granular

This demo shows fluid behavior as many local particle interactions. Crowded
particles push apart through pressure. Viscosity makes neighboring velocities
more similar. The result is splashy or syrup-like motion depending on the
controls.
