# Mass-Spring Cloth

Theme: Cloth, Hair & Fibers

This demo treats cloth as a grid of points joined by springs. Gravity pulls
points down, springs resist stretching, damping removes jitter, and a circular
obstacle stops the sheet from passing through solid space.
