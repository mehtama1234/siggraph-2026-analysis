# Gaussian Splatting

Theme: Neural Rendering & Radiance Fields

This demo paints a scene with soft colored blobs. Each blob contributes a weight
that fades with distance from its center. More blobs increase detail and cost;
depth order changes how translucent contributions accumulate.
