# Motion Interpolation And Retargeting

Theme: Character Animation & Motion

This demo shows a body pose as joint angles plus bone lengths. Interpolation
blends between two poses. Retargeting keeps the motion pattern while changing
the body scale, and constraints reduce obvious foot sliding.
